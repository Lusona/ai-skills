# Contributor evidence exercise

This bounded, documentation-only exercise checks whether a contributor can select
relevant coverage and assess evidence using
[CONTRIBUTING](../../CONTRIBUTING.md#behavioral-evidence). It is not a runner or a live
host evaluation. All hosts, models, identities, dates, trials, transcripts, results,
and artifact identifiers inside the packets are fictional fixture data. No packet
describes a run performed for this change.

Freeze [cases.md](cases.md) and the evaluator-only [review-key.md](review-key.md)
before assessment. A human or agent may assess these records. Give a fresh
contributor-role assessor only CONTRIBUTING.md and
cases.md, with no key, expected answers, or prior assessments. Its task and response
fields are in cases.md. The packets are self-contained; inline evidence identifiers
refer to sections of that file, not files to fetch. The existing
[evidence-aware suite](../evidence-aware/README.md) remains a separate starting point
for behavioral trials.

An independent reviewer then receives the key, exact assessor response, frozen input
identifiers, and actual requirements diff. The reviewer compares observed assessments
with expected outcomes, records supporting passages, and reviews the diff against the
approved criteria. A discrepancy is retained and resolved rather than rewriting the
key to fit an answer. Keep actor inputs and evaluator materials separate by assignment;
these adjacent files are not an operating-system access boundary.

The coordinator retains actual input versions/hashes, assessor identity, exact observed
responses, independent reviewer identity/grades, disagreement, and limitations in the
owning change evidence record. Fictional packet actors and graders are distinct from
those actual exercise participants. Do not fill actual assessor/reviewer fields with
fixture identities or count packet trials as real trials. One assessment of all five
packets and one independent grading pass form the initial budget; any correction or
repeat needs a recorded reason and authority, retaining the earlier result.

This exercise demonstrates interpretation and usability of the requirements. It does
not establish installed-host adherence, runtime improvement, statistical significance,
model cost, or coverage of every skill. Static checks and independent review remain
necessary. Next action: coordinator freezes the inputs, assigns the blinded assessment,
then retains and independently grades the observed response.
